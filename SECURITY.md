# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Opfield, please report it responsibly.

**Do not open a public issue.**

Instead, email [support@opfield.dev](mailto:support@opfield.dev) with:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

You can expect an initial response within 72 hours.

## Supported Versions

Security updates are provided for the latest release only.

## Scope

This policy covers the Opfield application code. Third-party dependencies are tracked separately — if you find a vulnerability in a dependency, please report it upstream and notify us so we can update.
